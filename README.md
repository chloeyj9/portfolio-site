# Chloe's portfolio

Astro + Tailwind + Motion, with a Keystatic editing dashboard.

## Run it

```
npm install
npm run dev
```

- Site: http://localhost:4321
- Editing dashboard: http://localhost:4321/keystatic

In the dashboard, **Home page** holds the greeting, tagline, subtitle and scroll text,
and **Projects** holds each card's title, cover image, tags, year, description and order.
Saving writes straight into `src/content/` and the site updates instantly.
